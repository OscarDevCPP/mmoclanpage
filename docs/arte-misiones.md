# Arte del recorrido de misiones

El claro y los elementos del recorrido se dibujaron para este proyecto con SVG y CSS locales; no son recursos oficiales de Pokémon ni imágenes generadas. `public/missions/encounters.svg` contiene las ilustraciones propias de los encuentros. Los objetos, la mochila, las bolas, el tablón, los papeles, el escritorio y la caja de premio son composiciones CSS originales. El personaje reutiliza `public/admins/maykelsito.png`, existente en el proyecto, con su pose frontal; no se han inventado fotogramas de caminata.

La presentación muestra seis escenas y el personaje flota suavemente en un bucle mientras está visible. Con movimiento reducido no se anima. Al terminar o saltar se muestra una guía de consulta estática, sin personaje ni burbujas; también se puede repetir la presentación. La preferencia se guarda localmente cuando el almacenamiento está disponible; si está bloqueado, la guía sigue accesible durante la visita.

Las especies, objetos, correo, premio y ticket son ejemplos didácticos, no información de la misión vigente ni acciones dentro del juego. El anuncio semanal es la referencia real; esta web no envía correos.
