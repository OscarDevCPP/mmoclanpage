# Arte del recorrido de misiones

El claro y los elementos del recorrido se dibujaron para este proyecto con SVG y CSS locales; no son recursos oficiales de Pokémon ni imágenes generadas. `public/missions/encounters.svg` contiene las ilustraciones propias de los encuentros. Los objetos, la mochila, las bolas, el tablón, los papeles, el escritorio y la caja de premio son composiciones CSS originales. El personaje reutiliza `public/admins/maykelsito.png`, existente en el proyecto, con su pose frontal; no se han inventado fotogramas de caminata.

Las especies, objetos, correo, premio y ticket son ejemplos didácticos, no información de la misión vigente ni acciones dentro del juego. El anuncio semanal es la referencia real. La animación es breve y se desactiva con la preferencia de movimiento reducido.
