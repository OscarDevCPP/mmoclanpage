Guías de PvE · Muestra ficticia

Bosque de tinta

Una página larga pone a prueba la lectura cuando el texto no cabe en una hoja. En lugar de ocultarlo, esta muestra permite desplazar el contenido dentro de la página.

Los senderos de este bosque están dibujados con tinta inventada. Cada árbol recuerda una pregunta que todavía no tiene respuesta y cada claro ofrece un lugar para detenerse a leer.

Al ampliar la letra o reducir la ventana, la cantidad visible cambia. Un libro real necesitará una estrategia de paginación y una prueba con textos de distintas longitudes, imágenes y dispositivos.

Mientras tanto, este párrafo adicional existe para hacer visible el límite de una hoja fija. No representa una zona, una mecánica ni una recomendación del juego.

La continuidad importa más que la ilusión: si el espacio se agota, el lector debe poder alcanzar todo el contenido sin que desaparezca detrás de un borde decorativo.

Esta última frase marca el final de la muestra larga. Desplázate dentro de la hoja para comprobar que también se puede leer.
